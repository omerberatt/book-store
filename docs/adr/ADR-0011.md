## Bağlam

Faz 0'da arayüz Thymeleaf ile sunucu tarafında üretilecekti *(K-05)*. Jakarta EE'ye geçişle *(ADR-0010)* Thymeleaf'in doğal yeri kalmadı. Ders notları yalnızca REST API ve OpenAPI işliyor; bir arayüz katmanı içermiyor. Kitap mağazasının ise müşterinin tarayıcıdan kullanabileceği bir yüzü olmalı *(SPEC: katalog, sepet, sipariş, hesap, yorum)*.

## Karar

1. Uygulamanın tek giriş noktası REST API'dir *(`/api/v1`)*. Arayüz bu API'nin bir istemcisidir; iş kuralı içermez.
2. Arayüz, `app` modülünün `src/main/webapp` klasöründe, WAR ile birlikte sunulan sade HTML, CSS ve JavaScript sayfalarından oluşur *(katalog, kitap detayı, sepet, sipariş, hesap, yorum, yönetim)*. Derleme adımı, Node.js veya bir JavaScript framework'ü kullanılmaz; sayfalar `fetch` ile API'yi çağırır.
3. Hata mesajları API'nin RFC 9457 yanıtındaki `code` değerine göre seçilir; metinler Türkçe ve İngilizce iki sözlük dosyasında durur *(NFR-4)*.
4. **Kimlik doğrulama:** Jakarta Security ile yapılır. Parolalar `PasswordHasher` portunun BCrypt uygulamasıyla özetlenir; `IdentityStore`, `AccountFacade` üzerinden hesabı bulur. API çağrıları HTTP Basic ile, tarayıcı oturumu form tabanlı giriş ile doğrulanır. Ayrıntılar Faz 7'de ayrı bir ADR ile netleştirilir; bu konu ders kapsamı dışındadır.

## Değerlendirilen Alternatifler

| **Alternatif** | **Neden seçilmedi?** |
| --- | --- |
| Thymeleaf *(K-05)* | Spring dışında kurulumu dolambaçlıdır; ders kapsamında değildir. |
| Yalnızca REST API | Uygulama son kullanıcı tarafından kullanılamaz; yalnızca OpenAPI üzerinden denenebilir. |
| Jakarta Faces *(JSF)* | Ayrı ve ağır bir öğrenme alanı; ders kapsamı dışında. |
| React veya benzeri bir SPA | Node.js derleme hattı ve Java dışı ciddi bir iş yükü getirir *(SPEC kapsam dışı)*. |

## Sonuçlar

- **Olumlu:** Arayüz ve API aynı sözleşmeyi kullanır; arayüzün yapabildiği her şey API ile de yapılabilir *(API-1)*.
- **Olumsuz:** Sayfalar sunucuda üretilmediği için arama motoru dostu değildir ve JavaScript kapalı tarayıcılarda çalışmaz.
- **Risk:** Elle yazılan JavaScript büyüdükçe düzen bozulabilir; sayfa başına tek dosya ve ortak bir `api.js` yardımcı modülüyle sınırlanır.

| **Kural** | **Kim korur?** |
